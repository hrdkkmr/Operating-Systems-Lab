## Operating Systems Lab ##

A collection of Operating Systems laboratory assignments implemented using the xv6 operating system.

This repository focuses on hands-on implementation of core OS concepts including process management, CPU scheduling, process synchronization, semaphores, shared memory, deadlocks, resource allocation, and deadlock avoidance.

The implementations are primarily based on the xv6 x86 operating system and are designed to demonstrate how operating-system concepts work at the kernel and user-process level.
